# Project Instructions

## Assistant workflow

- After any edit to files in this project, always end the response with a suggested commit message.
- Commit messages follow the Angular conventional commits style: `type(scope): subject` (e.g. `feat(book): ...`, `docs(chapter1): ...`, `refactor(build): ...`, `fix(render): ...`). Use types feat, fix, docs, style, refactor, perf, test, chore, build, ci. The subject is imperative mood, lowercase, no trailing period, max ~72 characters.
- When a change is more than trivial, add a body (blank line after the subject) with bullet points describing the notable changes in detail.
